# OpenTerminalUI Evaluation Record

## Decision

OpenTerminalUI was not present in the repository and has not been installed, forked, copied, or used as the application foundation. The approved architecture is a clean ARGUS-owned modular product.

## Permitted future use

A later task may approve examination of a narrow interaction or implementation technique. Such work must define its boundary, verify licensing, record attribution obligations, and independently implement an ARGUS-appropriate result. Wholesale templates, protected assets, and recognizable copied layouts remain excluded.

## Phase 1 result

The workstation shell, components, tokens, formatting rules, API contracts, and documentation in this repository are ARGUS-owned. Third-party runtime libraries are selectively used for general capabilities (React, Recharts, Vite, FastAPI) rather than application identity or architecture.
